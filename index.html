คู่มือการใช้งานระบบ (PowerPulse IoT User Manual)

เอกสารแนะนำการใช้งานฟีเจอร์ต่างๆ และคำสั่งเสียงอัจฉริยะสำหรับผู้ใช้งานและคณะกรรมการ

1

การมอนิเตอร์ค่าไฟฟ้าแบบเรียลไทม์ (Dashboard)

แสดงค่าแรงดัน (V), กระแส (A), กำลังไฟฟ้า (W) และพลังงานสะสม (kWh) จากบอร์ด ESP32 อัปเดตอัตโนมัติทุก 3 วินาที พร้อมกราฟเส้นแสดงแนวโน้ม 24 ชั่วโมง

2

การใช้งานระบบสั่งงานด้วยเสียง (Voice Control)

กดปุ่ม สั่งงานด้วยเสียง ในหน้าหลัก แล้วพูดคำสั่งภาษาไทยเพื่อควบคุมระบบได้ทันที:

• ไปยังหน้าต่างๆ: "หน้าหลัก", "หน้าประวัติ", "หน้าตั้งค่า", "หน้าระบบ"
• ควบคุมระบบ: "ปิดเสียง", "เปิดเสียง", "รีเซ็ตข้อมูล", "ทดสอบเตือนภัย"
• เครื่องมืออื่นๆ: "เปลี่ยนธีม", "เปลี่ยนภาษา", "ดาวน์โหลดประวัติ"
3

การส่งออกข้อมูลและตั้งค่าอัตราค่าไฟ

สามารถเลือกประเภทสถานที่ (บ้าน / หอพัก / ร้านค้า) เพื่อคำนวณค่าไฟ หรือกดดาวน์โหลดไฟล์รายงาน (.CSV) นำไปเปิดใน Excel ได้ที่หน้า ประวัติ & ตั้งค่า
